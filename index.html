How it works

      
    
        
  • The contract calls balanceOf on the Agent ID registry (0x60B9…022F) for both the voucher and the recipient on every vouch.
    • 
        
  • Names are resolved by the registry itself (ownerOfHandle), so alice.ai always means the address that holds that Agent ID.
    • 
        
  • Each vouch is an edge in a public graph: who vouches for whom is readable straight from the contract.
    • 
        
  • No admin keys: nobody but the voucher can add or remove their vouch. The source is verified on BscScan.
    • 
        
  • Share a link to your profile so others can vouch for you: …/#yourname.ai
